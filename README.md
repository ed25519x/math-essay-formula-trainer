# 수학 논술 공식 트레이너

가천대·국민대 논술 수학(수1·수2, 국민대는 미적분 포함) 대비용 공식 암기 & 실전 문제 웹앱입니다.

## 기능

- **범위 선택**: 수1 / 수2 / 미적분(국민대 대비)을 자유롭게 조합
- **공식 암기 모드**: 공식의 핵심 부분을 빈칸으로 가리고 연습
  - TeX 입력 모드: 세로로 펼쳐지는 수식 키패드 (가로 스크롤 없음) + 그 카드에 실제로 나오는 기호(`f(x)`, `f'(x)`, `\sin` …)를 맨 위에 단축키로 제공
  - 입력칸 수식으로 보기: 포커스를 떼면 입력한 TeX를 렌더링해서 보여줌
  - 객관식 모드: 보기 중에서 선택
  - LaTeX 코드 보기 토글로 수식의 실제 LaTeX 문법도 함께 공부
  - 채점은 넉넉하게: 공백/곱셈기호 생략(`2\cdot x` = `2x`), `\frac{1}{a}` = `1/a`, 프라임 표기(`'` `` ` `` `’` `^{\prime}`), "없다/없음/X/∅" 동일 처리
- **문제 풀이 모드**: 매번 새로 생성되는 숫자 문제
  - 어시스트 모드: 이동 중(예: 런닝머신)에도 풀 수 있도록 단계별로 숫자만 입력
  - 수동 모드: 집에서 끝까지 직접 풀고 최종 답만 채점
  - 답은 분수 입력 가능 (`3/4`), 모바일 숫자 키보드에 없는 `-` `/` `.` 보조 버튼 제공

## 문제 생성 엔진

`src/lib/` 에 나뉘어 있습니다.

| 파일 | 역할 |
| --- | --- |
| `rng.ts` | 시드 기반 난수 (같은 시드 → 같은 문제, 테스트 재현 가능) |
| `texfmt.ts` | 부호·분수·다항식 TeX 포매팅 (`x^2--9` 같은 깨진 식 방지) |
| `numeric.ts` | 심프슨 적분·수치 미분·극한 근사 (정답 검산용) |
| `problems.ts` | 35종 문제 생성기 (단원·주제·난이도 1~3) |
| `session.ts` | 적응형 출제 엔진 |

출제 엔진이 하는 일:

- **적응형 난이도**: 맞히면 목표 난이도가 올라가고 틀리면 내려간다.
- **주제 분산**: 이번 세션에 덜 나온 단원/주제에 가산점, 방금 나온 유형은 제외.
- **오답 복습**: 틀린 유형은 같은 세션 뒤쪽에서 숫자만 바꿔 한 번 더 출제.
- **중복 방지**: 숫자까지 같은 문제가 두 번 나오지 않는다.
- **깔끔한 답**: 삼각비·적분 구간 등을 정수/유리수 답이 나오는 조합만 미리 계산해 두고 사용 (`0.866` 같은 답 대신 `1/2`, `7`).

### 정답 검증

각 생성기는 공식으로 만든 정답과 별개로 `verify()` (수치 적분/미분/극한/합)를 제공합니다.
`bun test` 가 생성기마다 60개 인스턴스를 만들어

1. 모든 `$...$` 수식을 KaTeX로 실제 렌더링하고,
2. `decimals: 0` 인 답이 정수인지 확인하고,
3. 공식으로 구한 답과 수치 계산 결과가 일치하는지 비교하고,
4. `--`, `+-` 같은 부호 오류가 없는지 검사합니다.

## 개발

```bash
bun install
bun run dev      # 개발 서버
bun run build    # 프로덕션 빌드 (dist/)
bun test         # 문제 생성기·채점 로직 테스트
```
