# 수학 논술 공식 트레이너

가천대·국민대 논술 수학(수1·수2, 국민대는 미적분 포함) 대비용 공식 암기 & 실전 문제 웹앱입니다.

## 기능

- **범위 선택**: 수1 / 수2 / 미적분(국민대 대비)을 자유롭게 조합
- **공식 암기 모드**: 공식의 핵심 부분을 빈칸으로 가리고 연습
  - TeX 입력 모드: 모바일에서도 쓰기 쉬운 수식 키패드로 직접 입력
  - 객관식 모드: 보기 중에서 선택
  - LaTeX 코드 보기 토글로 수식의 실제 LaTeX 문법도 함께 공부
- **문제 풀이 모드**: 실제 숫자가 들어간 문제를 풀이
  - 어시스트 모드: 이동 중(예: 런닝머신)에도 풀 수 있도록 단계별로 숫자만 입력
  - 수동 모드: 집에서 끝까지 직접 풀고 최종 답만 채점

## 개발

```bash
bun install
bun run dev      # 개발 서버
bun run build    # 프로덕션 빌드 (dist/)
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 자동으로 빌드하여 GitHub Pages에 배포합니다. 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 합니다.
